# 🧮 Το Παιχνίδι της Προπαίδειας (Flashcards)

Μια διαδραστική εκπαιδευτική εφαρμογή για την εκμάθηση της προπαίδειας με τη μέθοδο των ψηφιακών καρτών (flashcards). Σχεδιασμένο για να κάνει την εξάσκηση διασκεδαστική και οπτικά ελκυστική για τους μαθητές.

## ✨ Χαρακτηριστικά
* **Εξατομικευμένη Μάθηση:** Επιλογή συγκεκριμένων αριθμών προπαίδειας για εξάσκηση.
* **Διαδραστικές Κάρτες:** Εφέ εμφάνισης (slide & fade) και αποκάλυψη απάντησης με το πάτημα ενός κουμπιού.
* **Παρακολούθηση Προόδου:** Ζωντανή μπάρα προόδου (Progress Bar) και μετρητής σωστών απαντήσεων.
* **Εντυπωσιακό Φινάλε:** Μεγάλη τελική οθόνη επιβράβευσης με εφέ μπαλονιών.
* **Responsive Design:** Πλήρης συμβατότητα με διαδραστικούς πίνακες, tablet και κινητά.

## 🚀 Πώς να το χρησιμοποιήσετε
1. Επιλέξτε τους αριθμούς που θέλετε να μελετήσετε από την αρχική οθόνη.
2. Πατήστε **🚀 ΞΕΚΙΝΑΜΕ!**.
3. Προσπαθήστε να βρείτε το αποτέλεσμα και πατήστε **ΔΕΣ ΤΗΝ ΑΠΑΝΤΗΣΗ 💡** για επιβεβαίωση.
4. Δηλώστε αν το βρήκατε σωστά για να προχωρήσετε στην επόμενη κάρτα.

## 🛠️ Τεχνολογίες

* **Streamlit Framework**
* **Custom CSS3** για animations και layout
